# Gemini on Tigrinya numbers (2026-10-28, raw answer)

Here is a guide to spoken and written Tigrinya numbers for ASR normalization.

---

### 1. Spoken Variants of 1500 and the Year 2015

#### **1500 (One Thousand Five Hundred)**
In Tigrinya, the leading **ሓደ** (*one*) before **ሽሕ** (*thousand*) is **optional** in natural speech, exactly like Amharic.

| Variant | Tigrinya Text | Notes |
| :--- | :--- | :--- |
| **Full / Standard** | ሓደ ሽሕን ሓሙሽተ ሚእትን | Both groups take the `-ን` suffix (*most formal/complete*) |
| **Leading ሓደ omitted** | ሽሕን ሓሙሽተ ሚእትን | Very common in speech |
| **Single conjunction (first)** | ሓደ ሽሕን ሓሙሽተ ሚእቲ | Very common |
| **Omitted ሓደ + single conjunction** | ሽሕን ሓሙሽተ ሚእቲ | Very common |
| **Bare / No conjunction** | ሓደ ሽሕ ሓሙሽተ ሚእቲ / ሽሕ ሓሙሽተ ሚእቲ | Common in fast speech / listing figures |
| **"Fifteen hundred" style** | ዓሰርተ ሓሙሽተ ሚእቲ | **Heard in commerce/currency**, but significantly less common than the *ሽሕ* forms |
| **Spelling variants of thousand** | ሺሕ / ሺ | Standard Tigrinya is **ሽሕ**; **ሺሕ** or **ሺ** appear under Amharic orthographic influence |

---

#### **The Year 2015**
In spoken Tigrinya, years are virtually always spoken as full thousands + remainder.

| Variant | Tigrinya Text | Notes |
| :--- | :--- | :--- |
| **Standard (Double `-ን`)** | ክልተ ሽሕን ዓሰርተ ሓሙሽተን | Standard full spoken form |
| **Single conjunction (first)** | ክልተ ሽሕን ዓሰርተ ሓሙሽተ | Very common |
| **Single conjunction (last)** | ክልተ ሽሕ ዓሰርተ ሓሙሽተን | Heard occasionally |
| **No conjunction** | ክልተ ሽሕ ዓሰርተ ሓሙሽተ | Very common in rapid news/speech |
| **Optional prefix** | ዓመተ ምሕረት (or ዓ.ም.) ክልተ ሽሕ... | Spoken when referring to Ethiopian/Eritrean calendar |
| **"Twenty fifteen" style** | *ዕስራ ዓሰርተ ሓሙሽተ* | ⚠️ **Unnatural / rare**. Only occurs among diaspora or young code-switchers calquing English. Do not prioritize for native speech. |

#### **Teens (11–19)**
Unlike Amharic (which shifts *ዓሰርተ* to *አስራ*), Tigrinya **keeps the cardinal base unchanged**: `ዓሰርተ + <digit>`.

* 11: **ዓሰርተ ሓደ**
* 12: **ዓሰርተ ክልተ**
* 13: **ዓሰርተ ሰለስተ**
* 14: **ዓሰርተ ኣርባዕተ**
* 15: **ዓሰርተ ሓሙሽተ**
* 16: **ዓሰርተ ሽድሽተ** (or *ዓሰርተ ሸድሽተ*)
* 17: **ዓሰርተ ሸውዓተ** (or *ዓሰርተ ሾብዓተ*)
* 18: **ዓሰርተ ሸሞንተ** (or *ዓሰርተ ሾሞንተ*)
* 19: **ዓሰርተ ትሽዓተ**

*Note on conjunctions in teens:* While `ዓሰርተ ሓደ` is standard, speakers occasionally say **ዓሰርተን ሓደን** or **ዓሰርተን ሓደ**.

### 3. Conjunction (`-ን`) Rules for Compound Numbers

The coordinating conjunction in Tigrinya is the enclitic suffix **`-ን`** (*-n* after vowels, *-ən* after consonants).

#### **Tens + Units (e.g. 25: ዕስራ + ሓሙሽተ)**
Speakers use three patterns (all valid in ASR):
1. **Symmetric (Standard):** `ዕስራን ሓሙሽተን` (both take `-ን`)
2. **First only:** `ዕስራን ሓሙሽተ` (very common)
3. **No conjunction:** `ዕስራ ሓሙሽተ` (very common in rapid speech)

#### **Compound Scale Groups (e.g. 1,234)**
* **Full form:** ሓደ ሽሕን ክልተ ሚእትን ሰላሳን ኣርባዕተን
* **Collapsed/Spoken form:** (ሓደ) ሽሕ ክልተ ሚእቲ ሰላሳን ኣርባዕተን (often only the final ten+unit pair retains `-ን`).

### 4. Ordinals

Tigrinya uses two systems for ordinals:

#### **System A: Analytical (`መበል` + Cardinal)**
Applicable to all numbers from 1 to infinity. This is the **primary system used above 10**.
* 1st: **መበል ሓደ**
* 2nd: **መበል ክልተ**
* 11th: **መበል ዓሰርተ ሓደ**
* 20th: **መበል ዕስራ**
* 100th: **መበል ሚእቲ**

#### **System B: Synthetic / Ge'ez-derived (1st–10th)**
Frequently used in both speech and writing for single digits (they decline for gender):

| Rank | Masculine | Feminine |
| :--- | :--- | :--- |
| 1st | **ቀዳማይ** | **ቀዳመይቲ** |
| 2nd | **ካልኣይ** | **ካልአይቲ** |
| 3rd | **ሳልሳይ** | **ሳልሰይቲ** |
| 4th | **ራብዓይ** | **ራብዐይቲ** |
| 5th | **ሓምሻይ** | **ሓምሸይቲ** |
| 6th | **ሳድሳይ** | **ሳድሰይቲ** |
| 7th | **ሳብዓይ** | **ሳብዐይቲ** |
| 8th | **ሳምናይ** | **ሳምነይቲ** |
| 9th | **ታስዓይ** | **ታስዐይቲ** |
| 10th | **ዓስራይ** | **ዓስረይቲ** |

*ASR Note:* Speakers sometimes redundantly combine both systems for 1–10 (e.g. **መበል ቀዳማይ**, **መበል ካልኣይ**). Your normalizer should recognize both `መበል + <cardinal>` and `መበል + <synthetic ordinal>`.
